==============
Zyte Spidermon
==============

Overview
========

Zyte spidermon is a collection of useful tools for data validation, stats monitoring, and notification messages for Scrapy projects running on `Zyte Scrapy Cloud <https://www.zyte.com/scrapy-cloud/>`_. This package is dependent on https://github.com/scrapinghub/spidermon and requires Python 3.10+.

Install
=======

The quick way::

    pip install zyte-spidermon
